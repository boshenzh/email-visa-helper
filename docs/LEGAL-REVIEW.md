# Legal review gate

Public launch is blocked. Personalised immigration advice is blocked. This file records the boundary the code enforces. It is not legal advice and it is not clearance.

## What counsel still has to decide

- Whether any function of this inbox is immigration advice or immigration services under section 84 of the Immigration and Asylum Act 1999, including when the operator, the staff, or the automation is in the UK.
- That form filling is not a blanket exemption, and that an AI label, a disclaimer, a free service, or a server outside the UK is not an exemption that this project can claim.
- Who, if anyone, is the qualified person (IAA registration, an approved regulator, or real supervision by such a person). Ordinary review of a draft is not that supervision.
- The controller, the lawful basis, retention, and the transfer terms before any real identity record is stored. DeepSeek’s API terms put end-user notice and a lawful basis on the developer. They do not, in the text read on 2026-11-08, state a zero-retention or no-training rule for API inputs.
- The conflict between a short demo TTL and any longer retention that would apply to a real client file. The code’s 30-day sweep is a product setting for this demo store only.

Until those are decided, the program may publish general procedural information, signpost the official checker and the adviser finder, and copy an applicant’s own words into a worksheet that says it is not an application and not a finding that the rules are met.

## Categories

| Category | Code behaviour |
| --- | --- |
| `GENERAL_INFORMATION` | Official snapshot and links. Not a personal recommendation. |
| `CLERICAL_APPLICANT_CONTROLLED` | Worksheet of the applicant’s words for an ordinary visitor request with no complication flag. |
| `REGULATED_REVIEW_REQUIRED` | Refusal, minor, work, study, marriage, medical treatment, paid engagement, transit exemptions, dual nationality, existing permission, inconsistent facts, a VAC/passport conflict, or a request for a personal verdict. No eligibility worksheet. |
| `OUT_OF_SCOPE` | Not visa preparation. No tools. |

The Home Office caseworker guidance read for this repo says advice or services in the course of a UK business, paid or not, require a qualified person, and that doing the work without qualification is an offence. That is a pointer to the guidance, not a conclusion about this operator. The August 2025 IAA practice note was used from the project research brief; the PDF was not downloaded again in the coding session.

## Still refused by the software

Submitting a form, paying a fee, making a declaration, collecting biometrics or passwords, posting a passport, choosing evidence because it “proves” a requirement, and emailing UKVI or a visa application centre.
